# CyberAudio v0.2.0

Second CyberAudio build, focused on free web-media link support and compatibility with the user's existing Fabric setup.

## Added
- Fabric Loader requirement lowered to **0.18.4+**
- YouTube, YouTube Music, Shorts, live-video, and playlist URL routing
- Spotify track, album, playlist, artist, show, and episode URL routing
- Optional in-game MCEF web player
- Direct MP3/OGG playback remains available without MCEF
- Web-media failures are intended to leave native audio available

## Important
This version is **superseded by v0.2.1**. On the target Mac it could crash when opening CyberAudio with **M** because the native player screen still had a hard JVM reference to the MCEF-backed screen class. v0.2.1 isolates MCEF behind reflection and fixes that architecture.

Kept as an archived development release for version history.
