# CyberAudio v0.2.1

Crash-safety and playlist release for Minecraft 1.21.11 Fabric.

## Fixed
- Pressing **M** now opens a Minecraft-native CyberAudio screen without directly loading MCEF classes.
- YouTube/Spotify web playback is isolated behind a reflection-based launcher and only loads after a web-media item is selected.
- MCEF launch and cleanup failures are caught so native CyberAudio features can remain usable.

## Added
- Full native CyberAudio player UI
- Persistent named playlists stored in `config/cyberaudio-playlists.json`
- Create/delete playlists
- Add direct audio, YouTube, YouTube Music, and Spotify URLs
- Optional track names
- Track selection and paging
- Play selected / previous / next
- Remove tracks
- Move tracks up/down
- Playlist switching
- Existing direct MP3/OGG engine, volume controls, config persistence, and metrics

## Compatibility
- Minecraft 1.21.11
- Fabric Loader 0.18.4+
- Java 21
- Fabric API
- MCEF optional and only needed for YouTube/Spotify playback

This is the recommended release in the v0.2 line.
