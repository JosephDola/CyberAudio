# CyberAudio v0.1.0

First compiled CyberAudio prototype for Minecraft 1.21.11 Fabric.

## Included
- Native Minecraft CyberAudio screen
- Default **M** keybind
- Direct HTTP/HTTPS audio URLs
- Asynchronous URL resolution
- Streaming MP3 and OGG/Vorbis playback
- Play, pause/resume, stop, and independent volume
- Basic direct-audio queue
- Persistent `config/cyberaudio.json`
- Downloaded-byte and startup-latency metrics

## Historical limitations
- Requires Fabric Loader **0.19.3+**.
- Direct audio only; normal YouTube and Spotify links are not supported.
- No persistent named playlists.

This release is kept for project history. New users should install the latest CyberAudio release.
